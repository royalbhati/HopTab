Release notes

HopTab 1.5

17 November 2026 · macOS 14+

The biggest release since 1.0. One search box for everything on your Mac, a ⌘Tab that knows which apps belong together, and workspaces you build without ever opening Settings.

Download 1.5.0 brew install --cask royalbhati/tap/hoptab
New

⌥K finds anything

One search over your workspaces, running and installed apps, Chrome tabs, bookmarks and 30 days of history across every profile, recent VS Code / VSCodium / Cursor projects, and HopTab's own actions. The list is ranked by the app that was in front when you pressed it: in Chrome, tabs and history come first; in your editor, projects do.

Anything that matches nothing opens as a URL or a web search. ⌘Enter opens a link in a new Chrome window, ⌘⌫ closes a Chrome tab from the list, ⌘1–9 jumps to a row. Reading Chrome tabs asks once for Automation access.

Your own commands. Settings → Command Palette adds rows that open a link, file or folder, press a shortcut inside an app, run a shell command, or paste text. Scope a command to an app and it ranks first there. ⌘N in the palette turns whatever you typed into a new command. Commands export and import as JSON.

New

⌘Tab, with your workspace first

Turn on “Replace ⌘Tab” and HopTab's switcher takes over the key. Your active workspace's apps come first, every other running app after, in most-recently-used order. ⌥Tab is now strictly the workspace switcher.

Build workspaces without leaving the switcher. While it is open, P pins the highlighted app to the active workspace, 1–9 toggles it in any workspace, N starts a new workspace with it, ⌫ unpins. The footer shows where the app already lives.

Redesigned

The menu bar is your workspaces

Every workspace is a row: its app icons, name, how many apps are running, and its hotkey. Click to switch. Hover for Save & Close, Restore, Apply Layout, Edit and Delete. “New workspace from what's open” expands into a picker where you tick exactly the running apps you want.

The Now block shows what is happening: the current or next meeting with a Join button, a running focus session or Pomodoro, the time until your next screen break, and today's tracked time. Those need Pro; the rest of the panel is free. The old 12-cell snap grid is now one row of the four you actually use plus undo.

New

Browser profiles per workspace

Tie a workspace to a Chrome or Safari profile in Settings → Workspaces → Behaviour. Switching brings that profile's window to the front and opens one if there is none, so your Work and Personal browsing stop bleeding into each other. Safari has no profile API, so HopTab reads its File menu and window toolbars through Accessibility. ⌥K lists a “Switch to profile” row for each one.

New

A tour that checks your work

Onboarding is three steps: grant Accessibility, build your first workspace from what is running, then try each key. The last step ticks a row only when HopTab sees the key actually pressed. No reading, no “got it” buttons.

Faster

Switching that keeps up with your hands

Both switches now do the visible part first and the bookkeeping after. ⌘Tab and ⌥Tab activate the chosen app the moment you let go; the Accessibility reads that used to come before it, and that Electron apps answer slowly, now run afterwards. Workspace switches bring the incoming apps forward at once and snapshot the outgoing windows in the background instead of blocking for up to 1.5 s. Opening the switcher or palette no longer rebuilds its window, and app icons are cached.

Also new
  • Launch at login, one toggle in Settings.
  • Grow / shrink a split. ⌃⌥= and ⌃⌥- resize the shared edge between two snapped windows.
  • Space-aware workspaces. Pin a workspace to a macOS Space; switching goes there, and can pull its windows along.
  • Drag-away restore. Drag a snapped window off its spot and it returns to its pre-snap size under the cursor.
  • Launch orchestration. Per-workspace launch groups, delays and files to open.
  • hoptab://settings/<section> deep links.
Changed
  • Settings is organised by feature. Workspaces, Shortcuts, Calendar, Time Tracking, Screen Breaks, Automation, General. Each Pro pane explains itself before asking for a license.
  • Shortcuts shows the everyday set first. Sixths, ninths and the rare sizes sit under “More”. Existing bindings still fire.
  • Pro is one promise: HopTab switches your workspace for you. Time tracking, Pomodoro, focus sessions and screen breaks live under Labs.
  • Removed: Focus Border, Focus Dimming, Themes, Per-Profile Visuals and Auto-Declutter. They cost main-thread time on every switch and pulled focus from what HopTab is about.
Fixed
  • Snap shortcuts work while HopTab itself is in front, with the menu open or Settings focused.
  • Snapping HopTab's own Settings window no longer crashes the app.
  • The ⌥Tab panel keeps one width as the highlight moves.
  • The onboarding tour's keys work with the onboarding window in front.
  • Switching to an app with several windows no longer pops the window picker unless you turn that on.

Full technical notes and the signed download are on the GitHub release. The app is Developer ID signed and notarized; existing users get an update prompt in the menu bar.
